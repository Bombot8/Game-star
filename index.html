Espace jeu

FORTNITE Stats

Statistiques publiques d’une île

Entre le code d’une île publique Fortnite pour consulter ses indicateurs officiels Epic. Ces données concernent l’île entière, pas les performances d’un joueur.

Recherche via l’API officielle Fortnite Data API.
Les indicateurs disponibles comprennent les joueurs uniques, parties jouées, minutes jouées et pic de joueurs simultanés. Les îles doivent être publiques et découvrables ; certaines valeurs peuvent être absentes si le seuil minimal de données n’est pas atteint.
Les statistiques de compte Fortnite (victoires, éliminations, ratio) ne sont pas fournies par cette API publique.
